Ai Agent Skill Tutorial

发表于 2026-11-15 分类于 Ai ， Agent ， Skill
本文字数： 2.4k 阅读时长 ≈ 4 分钟

本章我们将会学习有关现代AI Agent以及Skill、MCP的知识，本章内容包括对Agent、Skill、MCP等名词进行解释、给出常见的skill源MCP源，以及提供Multiple集成式开源Agent平台。纵观全局，智能体整体工作流程如下：

AI模型是什么

这里的AI指的就是我们日常在手机安装的AI APP ，比如豆包、deepseek、ChatGPT、Claude和千问等软件。多模态的Ai一般可以上传文件（图片或音频）等，模型会根据你上传的文件信息与你在对话框反馈交流，或者直接通过你的文字输入或语音输入与你沟通，这就是我们常说的AI。

这种AI不能操作你手机或电脑的文件，与你交流的方式只有发送图片或发送文字。

Agent是什么?

Agent又被叫做智能体，是使用 AI 来实现目标并代表用户完成任务的软件系统（以软件形式安装在手机或电脑）。智能体可以同时处理文本、语音、视频、音频、代码等多模态信息，还可以对话、推理、学习和做出决策。它们可以随着时间的推移不断学习，并简化事务和业务流程。智能体可以与其他智能体协作，来协调和执行更复杂的工作流。其表现出了推理、规划和记忆能力，并且具有一定的自主性，能够自主学习、适应和做出决定。

代表：

 - Codex
 - Claude Code
 - Workbuddy
 - OpenClaw
 - Deepseek Harness
 - Hermes

Agent可以根据你的要求对文件进行查找和编辑，能够直接使用你的工具来完成你交代的任务。它可以代你进行聊天、可以帮你购物、可以帮你做excel表格、可以帮你写代码改代码以及帮你下载安装软件服务等。

Skill是什么？

Skill按中文翻译就是“技巧”的意思，在AI这里，Skill就是一个文件夹，这个文件夹下写的有某一类工作的工作规范。这个工作规范就是ai将要执行的标准。比如说你要Ai去给你做PPT, Ai 恰好有一个ppt-skill， 这个skill中写的有指导ai怎么去做PPT，比如要先找素材，再做动画，内容怎么写，字体什么的调什么型号。有的skill还会包含一些脚本，这些脚本只有一个作用，只能实现某个具体的操作（比如，打开powerpoint并建立一个3页的文档），这种固定行为的任务完全可以写成一个脚本，在需要的时候直接运行。

总结 ： Skill就是一个经验包(通用流程)，它会告诉Ai干什么事要用什么干。

Skills仓库：：

  • SKILLS-HUB
  • SKILLHEY
  • Topgo Skills

MCP 是什么？

MCP(Model Context Protocol)全称：模型上下文协议

在AI模型尝试使用工具解决问题的时候，MCP就在AI和工具之间做连接，MCP会告诉AI这个工具是怎么用的，你做这个的时候需要这么做才行，做那个的时候需要那么做才行。

MCP会告诉模型：

  • 有哪些工具可用
  • 每个工具是做什么的
  • 工具需要什么参数
  • 调用后会返回什么格式的数据

MCP仓库：

  • Model Scope
  • Awesome MCP Servers
  • Github MCP
  • MCP SO

你可以让不同的大模型拥有多种身份，可以让Deepseek等套着Codex的外壳去工作，并且不只是套外壳。模型同时还获取了Codex等的思考方式和解决问题使用的办法。
